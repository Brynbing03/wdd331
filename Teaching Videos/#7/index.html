2. Drop Caps

A drop cap makes the first letter of a paragraph really big, kind of like you see in magazines.

Once upon a time, there was a girl who loved creating cute websites. She discovered that CSS could make even the simplest paragraphs look like something from a magazine. With just a few lines of code, her website started looking so much more creative! 

p::first-letter {
  -webkit-initial-letter: 3;
  initial-letter: 3;
}

4. The ch Unit

The ch unit is based on the width of the number zero in the current font. It helps control how wide our paragraphs are.

45ch

Good typography makes websites easier to read. When a paragraph is too wide, it can be hard for our eyes to follow the text. When it is too narrow, the text wraps constantly. Using the ch unit helps us find a nice comfortable width for reading. 

max-width: 45ch;

5. The lh and rlh Units

These units help us keep spacing consistent based on the height of our text lines.

My Favorite Things

I love creating websites that are simple, colorful, and easy to use.

Why Spacing Matters

Consistent spacing helps everything feel more organized and easier to read. 

p {
  margin-bottom: 1lh;
}

h3 {
  margin-top: 2rlh;
}

6. The ex Unit

The ex unit is based on the height of a lowercase x in the current font. It can be useful for sizing little things next to text.

Here is a little square next to my text! 

.ex-square {
  width: 2ex;
  height: 2ex;
}
