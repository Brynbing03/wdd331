THE BASICS

How does scroll snap work?

You really only need two main CSS properties!

01

Scroll Snap Type

This goes on the parent container and tells the browser how scrolling should snap.

scroll-snap-type: x mandatory;
02

Scroll Snap Align

This goes on each child card and tells the browser where that card should line up.

scroll-snap-align: start;

THE BIG TAKEAWAY

Two properties. So many possibilities.

CSS Scroll Snap makes carousels, photo galleries, and horizontal card layouts easier to build. The browser handles the snapping for us!

scroll-snap-type: x mandatory; scroll-snap-align: start;
