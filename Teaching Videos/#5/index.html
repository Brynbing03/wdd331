Logical Properties + Writing Modes
01 / THE BASICS

Meet Inline & Block!

CSS uses two directions to understand how content flows. Inline follows the text, and block follows the lines.

Inline Axis

START → → → END

In English, text flows left to right.

Block Axis

Line one ↓ Line two ↓ Line three

New lines stack from top to bottom.

04 / WRITING MODES

Wait... Text Can Be Vertical?

The writing-mode property changes how lines are arranged. Try all three options!

こんにちは 世界へようこそ CSSは楽しいです

writing-mode: horizontal-tb;

Fun fact! Some Japanese and Chinese text can be written vertically. Logical properties work with those writing modes too!
05 / QUICK REFERENCE

Your Logical CSS Cheat Sheet

Here are some common physical properties and their logical replacements.

margin-left margin-inline-start
padding-top padding-block-start
border-left border-inline-start
width inline-size
height block-size
text-align: left text-align: start
Remember: Inline follows the text. Block follows the lines. Start and end adapt to the writing direction!
