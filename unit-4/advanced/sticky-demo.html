Introduction

Sticky positioning is a useful CSS feature that lets an element stay visible while someone scrolls through a page.

It is commonly used for navigation menus, sidebars, section headings, and tables of contents.

On this page, the table of contents on the left stays visible as you scroll through the different sections.

How Sticky Works

CSS sticky positioning combines normal document flow with fixed-like behavior.

The element scrolls normally until it reaches a specified offset, such as top: 2rem.

Once it reaches that point, it stays in place until the boundaries of its containing block require it to move.

position: sticky;
top: 2rem;

The Overflow Bug

Sticky positioning can stop working when an ancestor has overflow set to hidden, auto, or scroll.

This happens because the browser uses the nearest ancestor with a scrolling mechanism to determine the sticky element's scroll behavior.

If that ancestor is not actually scrolling, the sticky element may never reach the point where it becomes sticky.

The Fix

To fix the problem, we need to make sure there is no unnecessary overflow setting between the sticky element and the page's scroll container.

Instead of using overflow: hidden on the main layout wrapper, we can use overflow: clip when clipping is needed without creating a scrolling container.

We can also apply overflow: hidden to smaller decorative elements instead of the ancestor that contains our sticky sidebar.

Key Takeaways

Sticky positioning is a simple way to keep important information visible while scrolling.

The most important things to remember are to include an offset, check ancestor overflow properties, and make sure the sticky element has enough room to move.

This makes sticky positioning really useful for longer pages with navigation or important information that should stay visible.
